## Workshop description

Inthis 90-120minutes workshopyou willearnhow tomakebothflat,clustered,layered,embedded,interactive,on-Wiki and off-Wiki maps from sets of geo-referenced (P625) items in Wikidata.

You will do this in 3 modules of approx. 30-40 minutes each:

· Module 1: You willstart by making various basic flat and clustered maps in Wikidata using SPARQL queries. Next you will make some layered maps, where groups of tems can be togged on/off in the map.

· Module 2: After having explored maps in the Wikidata query interface, you are now ready to learn how to embed Wikidata-driven maps in other Wikimedia projects, such as Wikipedia and Commons (examples). In addition to SPARQL we willook at OpenStreetMap, GeoJSON and the Mediawiki Kartographer extension.

· Module 3: Finallyou wilearn the steps for creating interactive,layered Wikidata-driven maps thatcan be used off-Wiki, ie.in regular HTML pages.Inaddtition to the above tools & techniques we willuse some basic Python,Jupyter Notebooks S), Jupyter Canct tor-widaets.

See the full outline of the workshop for a more detailed description.

## Intended audiences

While this workshop is tech-focusedand willdiscuss basic Wikidata Wikipedia and Wikimedia Commons techniques and programming tools,it is meant to be approachable by beginning Wikidata contributors and programmers.The workshop leader, by no means anadvanced Python programmer nor Wikidata nor SPARQL guru himself,is providing examples and code snippets that you can easily adapt yourself with basic SPARQL, Wikidata and Python skils, to make them work for your own datasets.

As the workshop is comprised of three 30-40 minute modules, you can decide to skipthe modules that youfind too advanced (or basic) for your individual knowledge level.
